# 交接单目录

每个跨部门功能在这里新建一份交接单，文件名使用 `YYYY-MM-DD-任务编号-简短名称.md`。

复制 `功能交接单模板.md` 后填写，不要直接修改模板。

## 全栈项目模板

当项目包含独立前端、后端、数据库、登录权限或多环境部署时，使用[全栈项目协作规范](../全栈项目协作规范.md)，并按工作内容选择模板：

- [全栈项目交接单模板](全栈项目交接单模板.md)：记录跨前端、后端、数据库、测试和运维的完整交接。
- [API 接口契约模板](API接口契约模板.md)：先确定接口，再进行前后端开发和联调。
- [数据库变更模板](数据库变更模板.md)：记录迁移、备份、兼容和回滚。
