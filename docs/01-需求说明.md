# 需求说明

## 使用者

需要管理个人学习、工作或生活待办的人。

## 页面与流程

1. 用户在顶部输入任务名称，可选择优先级、截止日期、备注和分类。
2. 用户可在“学习”“工作”“生活”三个分类中为新任务选择一个分类。
3. 用户点击“添加任务”，新任务出现在任务列表中，并显示已选分类。
4. 用户可通过筛选查看全部、待完成、今天到期或已完成任务。
5. 用户勾选任务后，任务显示为已完成；再次勾选可以恢复。
6. 用户可删除不再需要的任务。

## 验收标准

- 空任务不能被添加，页面需要给出提示。
- 新增任务立刻显示在列表和统计中。
- 筛选结果与任务状态、截止日期一致。
- 刷新页面后，已新增的任务仍然存在。
- 删除任务后，刷新页面也不会再次出现。
- 填写备注后，备注会显示在对应任务下方，刷新页面后仍保留。
- 新增任务时，用户可选择“学习”“工作”或“生活”之一作为分类。
- 任务添加成功后，列表中能清楚显示其分类；任务的其他信息和操作不受影响。
- 刷新页面后，任务的分类仍与添加时一致。
- 分类功能上线前已存在的任务仍可正常显示、完成和删除，不能因缺少分类而报错或丢失。

## T-02 任务分类：第一版范围

### 本次包含

- 在新增任务区域提供“学习”“工作”“生活”三个固定分类供用户选择。
- 将用户选择的分类保存到该任务，并在任务列表中显示。
- 将分类与现有任务数据一起保存在当前浏览器；刷新后仍保留。
- 兼容已存在的无分类任务，不改动或删除它们。

### 本次不包含

- 按分类筛选、统计或排序任务。
- 修改已创建任务的分类。
- 添加、删除、重命名或自定义分类。
- 多人共享、账号登录和云端同步。
