# 今日清单

一个轻量的个人任务管理网站，支持任务优先级、截止日期、备注、分类、状态切换和筛选。

## 使用方式

网站使用原生 HTML、CSS 和 JavaScript，无需安装依赖或运行构建命令。

本地预览：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 数据说明

任务保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。清除网站数据或更换域名后，原有任务不会自动迁移。

## 项目协作

项目采用文档驱动的部门协作流程，需求、设计、开发、测试和发布运维记录位于 `docs/`。
